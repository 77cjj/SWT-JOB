# 副业与羊毛 (Side Hustles & Hacks)

> **实时活动与邀请链接**请查看站内 **[薅羊毛](/deals)** 页面（含当前奖励、过期状态与历史时间线）。下文为原理与深度攻略；具体金额与截止时间以该页与官网为准。

羊毛不是“稳赚清单”，而是一组有门槛、有资金占用、有税务后果的促销。先保证主职工资、住宿和返程资金，再考虑额外奖励；不要为了一个红包承担自己看不懂的交易或合规风险。

## 银行开户奖励

美国 checking / savings 促销更新很快，同一家银行还可能因州、渠道和日期出现不同版本。与其背金额，不如先用下面六个字段筛选：

| 字段 | 要确认什么 |
|---|---|
| 身份资格 | 是否接受 J-1、是否必须 SSN/ITIN、是否需要到店 |
| 奖励门槛 | Direct Deposit、存款余额、刷卡次数分别要多少 |
| 完成窗口 | 从开户还是注册优惠之日起计算，截止哪一天 |
| 资金占用 | 需要放多少钱、维持多久、提前取出会不会失格 |
| 账户成本 | 月费、最低余额、提前关户或奖励 clawback |
| 税务与记录 | 是否发 1099、离美后怎样收税表和登录账户 |

Doctor of Credit 的月度汇总适合发现候选，因为它把奖励、DD、funding、hard/soft pull 和地区限制压在同一条目里；但真正开户前仍要点击银行官方 offer 保存条款。站内 **[官方精选](/deals)** 采用相同逻辑做 SWT 向筛选。

> 不要通过修改转账备注、伪装 payroll 或反复试探银行识别规则来制造 “fake DD”。普通 ACH、Zelle 或本人账户互转是否计入，完全以活动条款和银行最终判定为准；失败时可能拿不到奖励，严重时还可能触发账户审查。

如果是第一次在美国开户，优先解决“稳定收工资、免月费、离境后还能管理”这三件事，再从符合条件的账户里选奖励更好的一个。短期连续开很多账户可能触发 ChexSystems 或银行内部风控。

参考：[Doctor of Credit 当月银行奖励汇总](https://www.doctorofcredit.com/best-bank-account-bonuses/) · [低存款门槛银行开户奖励](/docs/return/low-deposit-bank-bonuses)

## 换汇与汇款奖励

汇款平台的新人奖励看起来门槛低，但奖励和实际汇款成本必须分开算：

**净价值 = 收款人最终到账 − 同时刻其他平台可到账金额 + 确定能拿到的奖励**

同一平台的费用会随金额、走廊和付款方式变化。Wise 强调中间市场汇率与前置手续费；Remitly 等平台可能提供不同速度和促销报价。没有任何一家在所有金额、所有时间都固定最便宜。进入 **[换汇汇款列表](/deals)** 后，先看“适合谁”和风险提示，再用相同金额同时询价。

## 返现 App

积少成多，日常消费建议常备：

- **Rakuten**：网购跳转下单，Nike、Adidas 等常有 2–15% 返现；新人常有约 $30 奖励
- **Ibotta**：超市小票返现（Walmart / Target 等）
- **Fetch Rewards**：扫小票攒积分，可换礼品卡

## 宠物托运 / 飞行志愿者

- **收益**：约 **$300–500** / 次（或等值人民币）
- **原理**：帮他人同一航线托运宠物；用你自己的机票额度
- **风险极高**：务必确认中介可靠、文件齐全；**确认箱内为宠物而非违禁品**
