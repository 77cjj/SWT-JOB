# 资金与银行卡

赴美前不用把所有钱都换成现金。更稳的做法是把落地资金拆成三层：少量现金应急、能在美国刷的国际卡，以及抵美后用于收工资的美国 checking account。

## 先算首笔工资前的缺口

不少雇主按双周发薪，第一笔工资还可能受入职时间和 payroll 截止日影响。请按 **至少 2–3 周无工资** 做预算，而不是照抄一个固定携带金额。

| 要准备的支出 | 怎么估 |
|---|---|
| 住宿 | 押金 + 首周或首月租金 |
| 落地交通 | 机场到住处、前几天通勤 |
| 吃饭与日用品 | 按工作地物价估 2–3 周 |
| 入职支出 | 工服、防滑鞋、证件照等 |
| 应急金 | 至少覆盖一次临时住宿或改签 |

如果雇主包住、可步行上班，所需现金会明显下降；如果要先交押金、买车票或租车，则要提高预算。随身现金只保留能应付落地当天和银行卡失效的部分，其余资金放在可挂失、可追踪的账户里。

## 换汇与跨境汇款：比较“最终到账”

“零手续费”不代表最便宜。跨境汇款的成本通常同时藏在手续费、汇率差、付款方式费和中间行费用里。美国 CFPB 要求多数消费者跨境汇款在付款前披露费用、汇率和收款人预计到账金额；这些字段也正是你比价时应该看的。

### 一个可靠的比价动作

1. 在 2–3 个平台里输入 **相同汇款金额、相同收款国家和相同付款方式**；
2. 记录付款总额、汇率、全部费用、收款人最终到账和预计时间；
3. 优惠码单独记，不要把一次性新人奖励当成长期汇率；
4. 付款前截图保存报价与预计到账时间；
5. 第一次先小额测试，确认姓名、账号和收款渠道无误后再做大额。

| 方式 | 更适合 | 重点确认 |
|---|---|---|
| 银行电汇 | 大额、学校或机构指定收款 | 汇出费、中间行费、收款行费、SWIFT 信息 |
| Wise 等透明计费平台 | 想清楚看到汇率与手续费 | 付款方式不同会改变费用和速度 |
| Remitly / 熊猫速汇等汇款平台 | 家庭汇款、希望有更多收款方式 | 优惠汇率是否仅限首笔、最终到账是否更高 |
| 机场或线下兑换 | 只补少量应急现金 | 汇率通常不占优，不适合大额 |

站内 **[薅羊毛 · 换汇汇款](/deals)** 会整理可用平台和邀请活动，但实时汇率必须以付款页为准。平台自评、邀请人经验和社区实测都有立场，至少用一家官方报价交叉核对。

参考：[CFPB 跨境汇款费用与速度披露说明](https://www.consumerfinance.gov/compliance/circulars/consumer-financial-protection-circular-2024-02/) · [Wise 官方费用说明](https://wise.com/us/pricing/send-money) · [Remitly 美国汇款页](https://www.remitly.com/us/zh/money-transfer)

## 国内国际卡

出发前准备一张可在美国使用的 Visa 或 Mastercard，并确认：

- 是否开通境外交易和线上交易；
- 境外交易手续费、ATM 取现费和每日限额；
- 银行预留手机号在美国能否收验证码；
- 丢卡后如何冻结、补卡或联系家人协助。

卡片姓名尽量与护照一致。不要把卡号、有效期和 CVV 发给陌生人，也不要把大额资金长期留在无法及时挂失的卡里。

## 美国本地银行账户

抵美后通常需要 checking account 接工资和 Direct Deposit。开户材料因银行、州和网点而异，常见组合包括护照、DS-2019、美国地址、Job Offer、SSN 或 SSN 申请证明。无 SSN 能否办理要提前问具体网点。

| 类型 | 用途 | 常见注意点 |
|---|---|---|
| Checking | 收工资、刷卡、缴费 | 看月费和免月费条件 |
| Savings | 分开放应急金、赚利息 | 看最低余额与转账限制 |

需要分清：**Account Number** 是银行账户号码，常用于工资和 ACH；**Debit Card Number** 是借记卡卡号，用于消费。补卡后卡号可能变化，账户号码通常不变。

### 收到纸质支票怎么办

- 可在开户行柜台或 ATM 存入；
- 多数银行 App 支持拍照存票，背面通常需要签名；
- 新账户或大额支票可能有 hold，App 显示“已提交”不等于资金已全部可用。

## 离美前别直接忘掉账户

先确认最后一笔工资、押金退款和税表地址，再决定保留还是关闭。关闭前下载流水、清空自动扣款并确认余额归零；如果保留，检查月费条件、美国手机号和二次验证是否还能使用。
